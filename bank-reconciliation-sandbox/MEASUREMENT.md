# Measuring time saved (fill this in with your own timings)

A time-saving claim is only worth making if you measured it. Method:

1. Pick 5 reconciliation cases from `evals/cases/` (mix of easy and trap cases).
2. **Manual baseline:** reconcile each one yourself in a spreadsheet. Time it with a stopwatch.
3. **With the skill:** run the skill (or MCP tools), then *review and correct* the draft.
   Time the whole thing, including review. A draft you don't check is not a saving.
4. Record the numbers:

| Case | Manual (min) | With skill + review (min) |
|---|---|---|
| case_ | | |
| case_ | | |
| case_ | | |
| case_ | | |
| case_ | | |
| **Total** | | |

Reduction = (manual total - assisted total) / manual total

State it exactly as measured, e.g. "cut effort by X% across 5 timed sample reconciliations".
These are small synthetic cases, so say so if asked.
